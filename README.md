# 自然言語によるロボットアーム制御

Dobot Magician とカメラ、OpenCV、ローカルLLM（Ollama）を組み合わせ、
日本語による自然言語の指示をロボットアームの制御コマンドへ変換する研究用プロトタイプです。

## 1. 目的

ロボットアームを専門的な操作コマンドではなく、自然言語による指示から操作できるようにすることを目的としています。

現在の実装では、入力した日本語の指示をLLMで制御コマンドへ変換し、
Python側でコマンドの内容・数値・単位を確認した上でDobotへ送信します。

また、カメラ画像から赤色物体を検出し、画像上の座標をロボット側の座標へ変換する処理も実装しています。

> 現在の研究用コードでは、自然言語の入力はキーボードから行います。

## 2. 主な機能

- 日本語による自然言語指示の入力
- Ollama / llama3.2 による指示内容の解析
- LLM出力をあらかじめ定義したコマンドへ制限
- 日本語の移動量から数値と単位（cm / mm）を取得
- cm → mm の単位変換
- OpenCVによる赤色物体の検出
- カメラ画像のピクセル座標からロボット座標への変換
- 「箱」の固定座標への移動
- Dobot Magician の移動制御
- HOME / STOP / CLEAR_ALARM
- ロボットの移動範囲の制限

## 3. システム構成

```text
日本語による指示
        │
        ▼
   Ollama / LLM
        │
        ▼
  制御コマンドへ変換
        │
        ▼
Python側で再確認
・許可されたコマンドか
・数値が正しいか
・単位が正しいか
        │
        ├──────────────┐
        ▼              ▼
  OpenCVによる       移動量を
  赤色物体検出       ロボット座標へ反映
        │              │
        └──────┬───────┘
               ▼
          移動範囲を制限
               │
               ▼
          Dobot Magician
```

## 4. 実装上の工夫

### LLMの出力をそのまま実行しない

LLMには `FIND RED`、`FIND BOX`、`MOVE_RIGHT` など、使用可能なコマンドを定義しています。

さらに、LLMの出力をPython側で確認し、許可されたコマンドだけを採用しています。

また、元の日本語入力から移動方向・距離・単位をPython側でも解析しています。

そのため、LLMが不要な移動を出力した場合でも、そのままロボットへ送らない構成にしています。

### 画像座標からロボット座標への変換

OpenCVで赤色物体の中心座標を取得し、事前に作成した変換行列 `matrix.npy` を使用してロボット側の座標へ変換します。

### 移動範囲の制限

ロボットへ移動指令を送る前に、X、Z、スライドレール方向の値を設定した範囲内に収めています。

```bash
pip install -r requirements.txt
```

Dobotの制御には `DobotDllType` を使用しています。
これは使用するDobot SDKの環境に合わせて配置してください。

## 7. 準備

### Ollama

Ollamaをインストールし、使用するモデルを取得します。

```bash
ollama pull llama3.2
```

### カメラ

現在のコードではカメラデバイス番号 `1` を使用しています。

必要に応じて `main.py` の以下を変更してください。

```python
cap = cv2.VideoCapture(1)
```

### 座標変換行列

カメラ画像の座標をロボット座標へ変換するため、`matrix.npy` をプロジェクトのルートディレクトリに配置してください。

```text
natural-language-robot-arm-control/
├── main.py
├── matrix.npy
└── ...
```

`matrix.npy` は実機環境で取得した座標変換用のデータです。

## 8. 実行

必要な機器を接続した状態で、

```bash
python main.py
```

を実行します。

例えば、

```text
赤い物を探して
```

のような日本語指示を入力すると、赤色物体の検出処理を行います。

移動指示では、

```text
赤い物を探して、前に5センチ動いて
```

のように、対象と移動内容を組み合わせて指定できます。

終了する場合：

```text
exit
```

## 10. 注意事項

このリポジトリは大学の研究で使用しているプロトタイプです。

実機の座標、カメラ位置、スライドレール位置などは使用環境によって異なるため、
実機へ接続する前に必ず移動範囲と座標を確認してください。

また、LLMの出力には不確実性があるため、コード内ではLLMの出力をPython側で確認してから実行する構成にしています。
